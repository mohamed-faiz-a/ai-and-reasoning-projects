# Vehicle Position Estimation

## Problem Statement
Estimate a vehicle's position from noisy GPS measurements.

## Inputs
- Simulated actual positions
- Noisy GPS measurements
- Process and measurement noise values

## AI Technique
Kalman Filtering.

## Expected Output
Estimated positions, a comparison graph, and RMSE values.

## Evaluation
Compare the measurement RMSE with the estimated-position RMSE.

## Implementation
Python, NumPy, and Matplotlib.
